ADB 指令测试Pixel 6 · 单设备
── ADB 指令控制台（输出仅作原型演示） ──
设备提示「未授权 USB 调试」怎么办？▶
首次连接时需要在手机上勾选「一律允许使用这台计算机进行调试」。若弹窗未出现，执行 adb kill-server && adb start-server 后重新插拔数据线即可触发。
ADB 连接超时 / 设备离线如何排查？▶
依次检查：① 数据线是否支持数据传输；② 无线调试需先在 adb tcpip 5555 后用 IP 连接；③ 后台服务会在连接超时后跳过本轮任务并写入运行日志，不会阻塞后续任务。
邮件发送失败（535 认证错误）？▶
QQ 邮箱必须使用「授权码」而非登录密码。进入邮箱「设置 → 账户 → POP3/SMTP 服务」开启服务并生成授权码，粘贴到「邮箱配置 → 授权码」输入框。
企业微信群里收不到消息？▶
确认 Webhook Key 与机器人所属群一致；同一机器人每分钟最多发送 20 条消息，超频会被限流。可在「企业微信配置」页点击「测试企业微信通知」快速验证。
节假日数据从哪里来，多久更新一次？▶
节假日数据来自 chinese-days 开源数据源（HTTPS CDN），覆盖全年法定节假日与调休。程序启动时自动检查，也可在「调度开关 → 同步节假日数据」手动更新。

本软件仅支持 Wi-Fi 无线连接，手机与电脑需接入同一局域网。输入设备 IP 点击「连接设备」，首次连接时设备上会弹出「允许 USB 调试吗？」，勾选「一律允许」即可。
